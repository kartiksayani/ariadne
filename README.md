# Ariadne

A local macOS workspace for conversations with running coding agents.
Claude Code is the primary integration; Codex is also supported by the design.

Status: repository foundation and implementation planning. The app is not built yet.

Development: Node 22.23.2 and Python 3.12 (3.11 also supported).
Install locked tools with `npm ci --ignore-scripts` and a Python virtual environment
using `requirements-dev.txt`. Quality hooks, specifications and the delivery harness
are being imported in small, checked commits.
