# ADR-0070: Install a Codex skill through one owned link

Status: Accepted by the owner, 2026-10-06.

Codex sessions did not know what Ariadne is until the owner pasted a setup
instruction. Codex CLI discovers personal skills in `$HOME/.agents/skills/<name>/SKILL.md`.

The installer places a generated Codex skill in the versioned package
(`integrations/codex-skills/ariadne/SKILL.md`) and creates one package-owned
symlink `~/.agents/skills/ariadne` to it, recorded in the owned link manifest. The
skill is generated by `gen-rules` from the same shared skill guidance and rule
sheet as the Claude skill, so it cannot drift.

The link is created only when absent or already recorded as Ariadne's. A foreign
file, directory or symlink, or a redirected `~/.agents` or `~/.agents/skills`, is
never overwritten or written through; the installer skips it and prints how to
link it by hand. Uninstall removes the link only when it is still that exact
link, and leaves `~/.agents/skills` in place. Older receipts without the link
remain valid.

Connecting a Codex session is unchanged: the owner selects the thread in the
Ariadne window and pastes the setup instruction. No connect command, CLI or MCP
contract, or rule-sheet wording changes. The skill states that an unconnected
thread must not guess a binding or claim saved work.
